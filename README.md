# Codex 桌面主题开发原型

这是独立于 DSH 皮肤仓库的新项目。`codex-theme-dev` 是临时开发目录和包名，正式名称以后再定；当前没有 GitHub 远端，也没有发布安装包。

第一版通过 Codex 自带的主题导入功能使用，不需要修改应用安装文件。提供冰蓝、雾灰、暮紫三组配色，每组有明亮和深色版本。

## 使用

1. 双击 `启动预览.cmd`，然后打开终端显示的本地地址；或使用 Node.js 22 及以上版本执行 `npm run preview`。
2. 在预览页选配色和明暗模式，调整颜色、对比度及半透明侧边栏，复制生成的主题文本。
3. 在 Codex 的 **设置 → 外观** 中，找到对应的 **明亮主题 / 深色主题 → 导入**，粘贴文本。深色主题要在深色主题区域导入，明亮主题同理。
4. 如果不满意，在 Codex 中重新选择内置主题；替换已有主题前也可以先用“复制主题”保存原设置。

预览页是颜色和布局示意。实际半透明效果由 Codex、Windows 和系统背景支持决定。字体使用本机已有字体，没有附带字体文件；未安装时系统会回退。

## 构建与检查

```powershell
npm run check
npm run build
npm run preview
```

无第三方运行依赖，无需安装 npm 包。`build` 在 `dist/` 生成六份 `.txt` 主题和 `manifest.json`。可以直接复制某份文本到 Codex 导入框。

检查涵盖原生格式往返、明暗模式匹配、颜色/字体/对比度校验、预设正文对比度，以及本地导出接口。按本机原生解析器核对格式，不将网页预览或测试通过称为真实应用导入成功。

## 当前能力

| 项目 | 状态 |
| --- | --- |
| 强调色、背景色、正文色、字体 | 原生主题文本支持 |
| 对比度、侧边栏半透明 | 原生配置支持；实际效果取决于宿主和系统 |
| 本地预览、复制和下载 | 此项目提供 |
| 流体背景、图片/视频壁纸、全界面毛玻璃 | 尚未实现；未找到可供原生主题使用的官方接入入口 |
| 自动安装、插件商店分发 | 尚未实现 |

这是原生主题的开发起点，不是 DSH 插件的直接移植，也不向 Codex 注入任意 CSS/JS。后续只有验证了宿主接入方式，才扩大效果范围。

## 文件

- `src/`：主题格式、配色预设和对比度计算。
- `web/`：本地预览与导出页面。
- `scripts/`：构建、检查及本地服务。
- `tests/`：主题格式和接口验证。
- `docs/compatibility.md`：原生格式来源、版本和能力边界。
- `dist/`：本地生成的可导入文本，不纳入源码提交。

保持独立 Git 历史；不依赖 DSH 的安装路径、插件加载器或设置存储，也不收录历史验证环境和凭据。当前使用 AGPL-3.0-only，与原项目的许可保持一致。
