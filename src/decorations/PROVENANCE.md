# Decoration sources

- `critters.ts` and `styles.ts` adapt the bubbles and plankton from [SuperSgdk/DSH-Liquid-Glass-Theme](https://github.com/SuperSgdk/DSH-Liquid-Glass-Theme/tree/98d2873334ce42e5cb26b5031165207d040645b1), inherited from John Wu (WYH66666666), copyright 2026. Their code is AGPL-3.0-only. The surrounding fish artwork and swim rules are removed.
- `particle-mark.ts` is the blue-white shark renderer created for the owner's confirmed visualization on 2026-10-02, then adapted to the existing main-column anchor and decoration API. It bundles 5,745 colored points, supports gentle drift, pointer displacement and return, and releases its observers, listeners and animation frames. It does not fetch an image or an SVG at runtime.
- The 2026-10-03 visual and performance repairs keep idle points aligned with the supplied reference: the whole mark drifts together as a cached bitmap, without independent dot jitter or a drop shadow. The Codex skin requests a 900ms outward burst and assembly on initial mounting via `replayOnMount`. A different visible conversation explicitly replays the same animation while reanchoring the retained canvases. An unfinished entrance survives a temporary null anchor and restarts when its anchor returns; once completed, restoring the same conversation does not replay it. The maximum holder is 504 CSS pixels, 1.2 times its original 420px size. The sampled positions and RGB data are unchanged.
- `shark-assembly-renderer.ts` is an original WebGL2 renderer for that same point data. Preparation compiles the shaders and uploads a fixed position, RGB and scatter buffer once; replay changes uniforms and draws all points in one batch per frame, capped at 60 GPU draws per second. Completion reveals the retained 2D bitmap. Reduced motion skips assembly; unavailable WebGL uses a finite Canvas2D animation capped at 15 draws per second. Mutable per-particle simulation is still created only for pointer interaction. Canvases, observers, listeners, queued work and GPU resources are released on disposal. These limits bound skin drawing work, rather than asserting a frame rate for native chat navigation.
- `shark-particle-data.json` contains only `width`, `height` and `[x,y,r,g,b,edge]` points sampled on a 164×160 grid. The original supplied PNG is not included. The dark background was excluded; blue and white colors, teeth and outline are preserved.
- SuperSgdk supplied the image, approved its particle use and publication for this project on 2026-10-02, and confirmed on 2026-10-03 that it is their own image. The artwork is credited to SuperSgdk and included with the owner's permission. The project's AGPL license applies to the code; a separate general artwork license has not been specified. Ask the owner before reusing the artwork in another distribution.
- The previous OpenAI / ChatGPT knot assets have been removed from public source. No application installation assets are needed by this renderer.

`mountDecorations(container, mainAnchor, options)` owns its nodes and resources. The legacy `whale` settings key remains compatible and now controls the shark; its visible label is “鲨鱼粒子”.
